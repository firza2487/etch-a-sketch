# Etch-a-Sketch

A browser-based sketchpad inspired by the classic Etch-a-Sketch toy, built with vanilla JavaScript, HTML, and CSS.

This project is part of **[The Odin Project – Foundations](https://www.theodinproject.com/paths/foundations/courses/foundations)** curriculum, focusing on DOM manipulation, event handling, and dynamic UI creation.

## Features

- **Interactive Sketchpad** — Draw by hovering or interacting with the grid.
- **Dynamic Grid** — Customize the grid size to create different drawing resolutions.
- **Clear Canvas** — Reset the sketchpad and start drawing from scratch.
- **Responsive Layout** — Adapt the interface to different screen sizes.
- **[Additional Feature]** — Add any extra functionality implemented in your project.

## Learning Objectives

This project was developed to practice and strengthen the following concepts:

- Creating and manipulating DOM elements dynamically.
- Handling mouse events and user interactions.
- Using JavaScript functions to manage application behavior.
- Applying Flexbox to construct a grid-based layout.
- Separating structure, styling, and functionality using HTML, CSS, and JavaScript.
- Managing project versions with Git and GitHub.
